Git

Learn just enough Git to start work: every part uses the vinc_course course management repository on GitLab and follows a real team workflow from commit to merge request and release. Little theory, every command really run.

Series: Practical Git for Development Teams

12 parts from installing and committing to branches, remotes, merge requests, conflicts, undoing, rebase, hooks, CI and a capstone project.

    What Git is, installing and first-time setup
