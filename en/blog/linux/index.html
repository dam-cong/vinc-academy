Linux & Shell

Master just enough Linux command line to get work done: moving around and managing files, permissions, processes, pipes and Bash scripts — the things you use every day with servers, Git and Odoo deployments.

Most servers run Linux, and nearly all deployment, debugging or automation work starts in a terminal window. Knowing the command line lets you read logs, find files, inspect processes and write scripts instead of doing things by hand.

This series is being written in the style of the other Vinc Academy topics: little theory, examples really run on Linux (WSL, a virtual machine or a server), each command with its output. Leave a message if you would like to hear when the first part goes live.
