Install Odoo 20: Source & Docker Guide for Developers

A clean development environment saves you hours of debugging later. This guide covers the two ways Vinc Academy installs Odoo 20 in class, plus the errors students hit most often and how to fix them.

Updated: October 16, 2026 11 min read – views Vinc Academy team

Quick answer

To install Odoo 20 for development you need Python 3.12+, PostgreSQL 16+ and Git. Clone the 20.0 branch from GitHub, create a dedicated PostgreSQL user, install the dependencies and run odoo-bin; or use Docker Compose with the odoo:20.0 and postgres:16 images. Open http://localhost:8069, log in with admin/admin and enable developer mode.

Before you install

Odoo 20 raises its minimum requirements compared to previous versions, so a machine that runs Odoo 17 or 18 is not necessarily ready. Check this list:

ComponentRequirementNotes
Python3.12 or laterCheck with python3 --version; pip must be available
PostgreSQL16 or laterDo not run Odoo with the postgres user

wkhtmltopdf0.12.6 (optional)Needed for PDFs with headers/footers; install manually, not via pip
Node.js + rtlcssOptionalOnly for right-to-left languages
pgvectorOptionalOnly when using Odoo's AI features

Vinc Academy's recommendation: learners should start with a source install, because it is the clearest way to understand how Odoo boots. Docker is a valuable extra skill once you work on real projects.

Option 1: Install Odoo 20 from source on Ubuntu

The steps below use Ubuntu/Debian, the most common setup among Odoo developers. Windows and macOS notes are at the end of this section.

Step 1: Get the source code

Fetch only the 20.0 branch to save space. --depth 1 skips the commit history and makes cloning much faster:

mkdir -p ~/odoo-dev && cd ~/odoo-dev
git clone https://github.com/odoo/odoo.git --branch 20.0 --single-branch --depth 1

If you have access to Odoo Enterprise, also clone the odoo/enterprise repository into ~/odoo-dev. It only contains extra modules and still runs on top of Community.

Step 2: Install PostgreSQL and create a dedicated user

Odoo refuses to connect with the postgres superuser. Create a user named after your Linux account, allowed to create databases:

sudo apt install postgresql
sudo -u postgres createuser -d -R -S $USER
createdb $USER

Check the version with psql --version. If your Ubuntu release ships a version older than 16, install it from the official PostgreSQL repository.

Step 3: Install dependencies

The Odoo documentation recommends the script shipped with the source, which installs the matching Debian/Ubuntu system packages:

cd ~/odoo-dev/odoo
sudo ./setup/debinstall.sh

To isolate libraries per project, you can use a Python virtual environment and requirements.txt instead. This needs system build packages such as libpq-dev, libldap2-dev and libsasl2-dev:

python3 -m venv ~/odoo-dev/venv
source ~/odoo-dev/venv/bin/activate
pip install -r requirements.txt

Step 4: Run Odoo

python3 odoo-bin --addons-path=addons -d odoo20_dev

Once the log shows odoo.modules.loading: Modules loaded., open http://localhost:8069 and log in with admin / admin. The odoo20_dev database is created automatically on the first run.

About demo data

Since Odoo 20, new databases have no demo data by default. While learning, add --with-demo when creating the database so you get sample customers, products and orders to practice with.

Windows and macOS notes

  • Windows: install Build Tools for Visual Studio (C++ workload), add PostgreSQL's bin folder to PATH and create a login role that can create databases in pgAdmin. Install libraries with pip install setuptools wheel then pip install -r requirements.txt, and pass the connection details: python odoo-bin -r dbuser -w dbpassword --addons-path=addons -d odoo20_dev.
  • macOS: install Command Line Tools with xcode-select --install, system libraries via Homebrew or MacPorts, and PostgreSQL via Homebrew or Postgres.app; then create the user and run Odoo as on Linux.

Option 2: Run Odoo 20 with Docker Compose

The official odoo image on Docker Hub already provides a 20.0 tag. Instead of typing several docker run commands, Vinc Academy uses one Compose file so the whole class gets identical environments:

odoo20/docker-compose.yml

services:
  db:
    image: postgres:16
    environment:
      POSTGRES_USER: odoo
      POSTGRES_PASSWORD: odoo
      POSTGRES_DB: postgres
    volumes:
      - db-data:/var/lib/postgresql/data

  odoo:
    image: odoo:20.0
    depends_on:
      - db
    ports:
      - "8069:8069"
    environment:
      HOST: db
      USER: odoo
      PASSWORD: odoo
    volumes:
      - odoo-data:/var/lib/odoo          # filestore, sessions
      - ./addons:/mnt/extra-addons       # your own modules

volumes:
  db-data:
  odoo-data:
cd odoo20
mkdir -p addons
docker compose up -d
docker compose logs -f odoo

Open http://localhost:8069 and Odoo shows the database creation page. Modules placed in ./addons appear inside the container at /mnt/extra-addons.

Common pitfall: PostgreSQL version

Many older guides and Docker examples still use postgres:15. Odoo 20 requires PostgreSQL 16 or later, so use postgres:16 (or newer) from the start and avoid migrating data later.

Enable developer mode

Developer mode unlocks technical tools: view structures, field and model names, menus, actions… It is the first thing an Odoo developer turns on every day. Equivalent ways to enable it:

  • From Settings: open the Settings app, scroll to Developer Tools and click Activate the developer mode.
  • Via URL: append ?debug=1, e.g. http://localhost:8069/odoo?debug=1; use ?debug=0 to turn it off.
  • JavaScript debugging: use ?debug=assets to load unminified JS/CSS files.
  • Command palette: press Ctrl + K (macOS: Cmd + K) and type "debug".

Once enabled, a bug icon appears in the menu bar. Some of its tools can change system data, so use them on development databases only.

odoo-bin options worth remembering

OptionPurpose
--addons-pathComma-separated list of module directories
-dDatabase to work with
-iInstall modules before starting the server (requires -d)
-uUpdate modules after changing code (requires -d)
--devDevelopment helpers, e.g. xml reads views straight from files, reload restarts on Python changes; all enables several at once. Never use in production
--with-demoInstall demo data in new databases
-p / --http-portChange the HTTP port (default 8069)
-c / -sUse a config file / save current options to the config file

Tip: run once with all your options plus -c ~/odoo-dev/odoo20.conf -s; afterwards python3 odoo-bin -c ~/odoo-dev/odoo20.conf is enough.

Scaffold your first module

With the environment ready, keep your own modules in a separate folder from the Odoo source. The scaffold command generates a standard module skeleton:

cd ~/odoo-dev
mkdir -p custom-addons
python3 odoo/odoo-bin scaffold vinc_course custom-addons

cd odoo
python3 odoo-bin --addons-path=addons,../custom-addons \
    -d odoo20_dev -i vinc_course --dev=xml

Open Apps (with developer mode on) and search for vinc_course to see the installed module. The next article explains everything inside it.

Recommended tools

  • Editor: VS Code or PyCharm, with PEP8 checks for Python and ESLint for JavaScript.
  • PostgreSQL client: pgAdmin or DBeaver to inspect the tables the ORM creates, very useful when learning models.
  • Python debugging: your editor's debugger, or pip install ipdb and add import ipdb; ipdb.set_trace() where you want to stop.
  • Odoo shell: python3 odoo-bin shell -c ~/odoo-dev/odoo20.conf opens a Python console with an env variable to try the ORM. Changes are only saved when you call env.cr.commit().

Two mistakes beginners often make

  • Running -i or -u without -d. According to the CLI reference, both options must be used together with a database name. Get used to always writing it in full: -d odoo20_dev -u module_name.
  • Editing data in odoo shell, exiting, and finding nothing changed. The shell only keeps changes when you call env.cr.commit(). That is deliberate, so you can experiment freely without damaging the database.

Frequently asked questions

Should I install Odoo 20 from source or with Docker? ▾
If you are learning to become an Odoo developer, install from source: it is easier to read the code, set breakpoints and debug. Docker is better for spinning up a clean environment quickly, running several versions side by side or preparing a deployment.
What is the default Odoo login? ▾
For a database created with the -d option of odoo-bin, the default administrator login is admin with password admin. Change it if the environment is reachable from outside.
Why does my new database have no demo data? ▾
In Odoo 20, new databases are created without demo data by default. Add --with-demo when creating the database if you want sample data for learning and testing.
Does Odoo 20 work with PostgreSQL 15? ▾
It is not recommended. The official Odoo 20 installation guide requires PostgreSQL 16 or later. Many older Docker examples still use postgres:15, so switch to postgres:16 or newer.
