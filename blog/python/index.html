Python

Học Python vừa đủ để làm việc: mỗi bài dùng ví dụ từ dự án quản lý khóa học và chỉ ra nó xuất hiện ở đâu trong mã Odoo. Ít lý thuyết, nhiều đoạn code chạy được.

Series: Python thực chiến cho lập trình viên Odoo

14 bài từ cài đặt môi trường, kiểu dữ liệu, hàm, OOP đến xử lý lỗi, file, API và một dự án nhỏ.

  1. Bài 01

    Làm quen Python: cài đặt, venv và pip

    Cài Python 3.12, tạo môi trường ảo, chạy script và cài thư viện cho dự án Odoo.

    – lượt xemĐã xuất bản
  2. Bài 02

    Biến, kiểu dữ liệu và chuỗi

    Số, chuỗi, f-string và ép kiểu qua ví dụ mã khóa học và thông báo log.

    – lượt xemĐã xuất bản
  3. Bài 03

    Điều kiện và vòng lặp

    if, for, while, match với danh sách khóa học, nền tảng của for record in self.

    – lượt xemĐã xuất bản
  4. Bài 04

    List, tuple, set và dict

    Các cấu trúc dữ liệu bạn gặp trong vals, domain và Command của Odoo.

    – lượt xemĐã xuất bản
  5. Bài 05

    Hàm: tham số, **kwargs và lambda

    Viết hàm gọn, dùng tham số mặc định và hiểu default=lambda self: trong Odoo.

    – lượt xemĐã xuất bản
  6. Bài 06

    Comprehension, generator và sorted/filter

    Xử lý danh sách gọn như mapped, filtered, sorted của recordset.

    – lượt xemĐã xuất bản
  7. Bài 07

    Module, package và import

    Cách Python tìm và nạp mã, và vì sao module Odoo có __init__.py.

    – lượt xemĐã xuất bản
  8. Bài 08

    Class và đối tượng

    Thuộc tính, method, @property và cách class Python trở thành model Odoo.

    – lượt xemĐã xuất bản
  9. Bài 09

    Kế thừa, super() và decorator

    Hiểu super().create(), @api.depends và tự viết decorator của riêng bạn.

    – lượt xemĐã xuất bản
  10. Bài 10

    Xử lý lỗi và câu lệnh with

    try/except, raise và exception tùy biến, tương ứng ValidationError, UserError.

    – lượt xemĐã xuất bản
  11. Bài 11

    Làm việc với file, JSON và CSV

    Đọc ghi file, pathlib, JSON và CSV để xuất nhập dữ liệu khóa học.

    – lượt xemĐã xuất bản
  12. Bài 12

    Ngày giờ và regex

    datetime, timedelta, múi giờ và regex để kiểm tra mã khóa học, email.

    – lượt xemĐã xuất bản
  13. Bài 13

    Gọi API với requests

    Gửi request, đọc JSON, xử lý lỗi và timeout, gọi thử API JSON-2 của Odoo.

    – lượt xemĐã xuất bản
  14. Bài 14

    Debug, logging, test và dự án nhỏ
