Python class và đối tượng: từ OOP cơ bản đến model Odoo

Mỗi model Odoo là một class Python. Bài này dạy OOP cơ bản qua class Course thuần Python, rồi đối chiếu với class VincCourse trong Odoo để bạn hiểu field là thuộc tính, self là recordset và tại sao quy ước đặt tên giống nhau.

Cập nhật: 16/10/2026 15 phút đọc Đội ngũ Vinc Academy

Tóm tắt nhanh

Class là khuôn, đối tượng (object) là sản phẩm tạo từ khuôn: c = Course("Odoo", 24). Trong class, __init__ khởi tạo dữ liệu, self là chính đối tượng đang dùng, thuộc tính lưu dữ liệu và method là hàm gắn với đối tượng. Model Odoo là một class kế thừa models.Model: field là thuộc tính của class, _name đặt tên model, và self trong method là một recordset, tức một tập đối tượng chứ không chỉ một.

Class và đối tượng cơ bản

Hãy dựng class Course thuần Python, mô phỏng khóa học trong dự án vinc_course:

class Course:
    prefix = "ODO"                       # thuộc tính của class (dùng chung)

    def __init__(self, name, hours, price=0.0):
        self.name = name                 # thuộc tính của từng đối tượng
        self.hours = hours
        self.price = price
        self.published = False

    @property
    def price_per_hour(self):            # đọc như thuộc tính, tính khi cần
        return self.price / self.hours if self.hours else 0.0

    def publish(self):
        if self.hours <= 0:
            raise ValueError("Số giờ phải lớn hơn 0")
        self.published = True

    def __repr__(self):
        return f"Course({self.name!r}, {self.hours}h)"
  • __init__ chạy mỗi khi tạo đối tượng. Tham số đầu tiên luôn là self, tham chiếu đến chính đối tượng đó; Python tự truyền nó khi bạn gọi Course(...).
  • self.name = name tạo thuộc tính của đối tượng; mỗi đối tượng có bộ thuộc tính riêng.
  • Method (như publish) là hàm khai báo trong class, tham số đầu tiên cũng là self.
  • __repr__ quyết định chuỗi hiển thị khi in đối tượng hoặc xem trong danh sách; thiếu nó bạn chỉ thấy dòng khó đọc như <Course object at 0x...>.
c = Course("Odoo cơ bản", 24, 4500000)
print(c)                      # Course('Odoo cơ bản', 24h)
print(c.name, c.hours, c.published)   # Odoo cơ bản 24 False
c.publish()
print(c.published, round(c.price_per_hour))   # True 187500

other = Course("Python", 16)
print([c, other])             # [Course('Odoo cơ bản', 24h), Course('Python', 16h)]
print(isinstance(c, Course), type(c).__name__)   # True Course

Điều đáng chú ý là c.publish() không cần truyền self: Python tự đưa c vào. Hàm isinstance(c, Course) kiểm tra một đối tượng có thuộc class nào đó không, và vars(c) cho bạn dict các thuộc tính của nó.

Thuộc tính của class và của đối tượng

Thuộc tính khai báo trực tiếp trong thân class (như prefix) thuộc về class và được mọi đối tượng chia sẻ; thuộc tính gán qua self. thuộc về từng đối tượng. Gán lại qua một đối tượng chỉ tạo thuộc tính riêng cho đối tượng đó:

print(Course.prefix, c.prefix)     # ODO ODO
c.prefix = "X"                     # tạo thuộc tính riêng cho c, không đổi class
print(c.prefix, Course.prefix)     # X ODO

class Bad:
    tags = []                      # list ở cấp class: dùng chung cho MỌI đối tượng
    def add(self, t):
        self.tags.append(t)

a, b = Bad(), Bad()
a.add("x")
print(b.tags)                      # ['x']   <- b cũng thấy!

class Good:
    def __init__(self):
        self.tags = []             # mỗi đối tượng có list riêng
    def add(self, t):
        self.tags.append(t)

a, b = Good(), Good()
a.add("x")
print(a.tags, b.tags)              # ['x'] []

Bẫy này giống hệt giá trị mặc định có thể thay đổi ở bài 5: một list ở cấp class bị dùng chung. Quy tắc: dữ liệu riêng của đối tượng luôn khởi tạo trong __init__.

Method đặc biệt (dunder) và so sánh đối tượng

Các method có tên dạng __ten__ được Python gọi ngầm khi bạn dùng cú pháp quen thuộc. Bạn đã gặp __init__ và __repr__; dưới đây là vài method hay dùng khác:

MethodĐược gọi khiVí dụ
__init__Tạo đối tượngCourse("Odoo", 24)
__repr__Xem đối tượng trong list, debug[course]
__str__print, f-stringf"{course}"
__eq__Phép ==a == b
__len__Hàm len()len(course)
 
class Course:
    def __init__(self, name, hours):
        self.name, self.hours = name, hours
    def __repr__(self):                 # dành cho lập trình viên (debug, list)
        return f"Course({self.name!r}, {self.hours})"
    def __str__(self):                  # dành cho người dùng (print, f-string)
        return f"{self.name} ({self.hours}h)"
    def __eq__(self, other):            # định nghĩa phép ==
        return isinstance(other, Course) and (self.name, self.hours) == (other.name, other.hours)
    def __len__(self):                  # len(course)
        return self.hours

a, b = Course("Odoo", 24), Course("Odoo", 24)
print(a == b, a is b)                   # True False
print(repr(a), str(a), len(a))          # Course('Odoo', 24) Odoo (24h) 24
print(f"{a}", [a])                      # Odoo (24h) [Course('Odoo', 24)]

Hai điểm đáng nhớ. Thứ nhất, == mặc định so sánh danh tính (có phải cùng một đối tượng không); muốn hai đối tượng có dữ liệu giống nhau được coi là bằng nhau, bạn phải tự viết __eq__. Toán tử is luôn kiểm tra cùng đối tượng. Thứ hai, __repr__ hướng tới lập trình viên (nên đủ thông tin để tái tạo đối tượng), còn __str__ hướng tới người dùng cuối; nếu chỉ viết một, hãy viết __repr__.

@dataclass: class chỉ để chứa dữ liệu

Với class chủ yếu để gom dữ liệu (kiểu như một dòng CSV hay một phản hồi API), viết __init__, __repr__ và __eq__ bằng tay rất lặp lại. Decorator @dataclass của thư viện chuẩn tự sinh chúng từ danh sách thuộc tính có chú thích kiểu. Với list hay dict làm mặc định, dùng field(default_factory=list) để tránh bẫy dùng chung đã nói ở bài 5:

from dataclasses import dataclass, field

@dataclass
class CourseDC:
    name: str
    hours: int
    price: float = 0.0
    tags: list = field(default_factory=list)   # mặc định list an toàn

d = CourseDC("Odoo", 24)
print(d)                                  # CourseDC(name='Odoo', hours=24, price=0.0, tags=[])
print(d == CourseDC("Odoo", 24))          # True
print(CourseDC("X", 1).tags)              # []  (mỗi đối tượng có list riêng)

Bạn sẽ dùng @dataclass ở bài 13 và 14 để mô tả dữ liệu đọc từ file hoặc API trước khi gửi vào Odoo.

Quy ước về tên: _ và __

Python không có thuộc tính "private" thực sự. Quy ước là một dấu gạch dưới đầu tên (_internal) báo hiệu "dùng nội bộ". Hai dấu gạch dưới (__secret) khiến Python đổi tên thuộc tính thành _TênClass__secret để tránh va chạm với class con, chứ không phải để giấu hoàn toàn:

class Acc:
    def __init__(self):
        self._internal = 1        # quy ước: nội bộ, đừng đụng từ ngoài
        self.__secret = 2         # tên bị đổi thành _Acc__secret

x = Acc()
print(x._internal, hasattr(x, "__secret"), x._Acc__secret)   # 1 False 2

Trong Odoo, tiền tố một gạch dưới còn có ý nghĩa mạnh hơn: method bắt đầu bằng _ không gọi được từ nút bấm hay API bên ngoài.

@property: tính toán nhưng dùng như thuộc tính

@property biến method thành thuộc tính chỉ đọc: c.price_per_hour không cần ngoặc và luôn được tính từ dữ liệu hiện tại. Gán vào một property không có setter báo AttributeError: property 'price_per_hour' of 'Course' object has no setter. Khi muốn kiểm tra giá trị lúc gán, thêm setter:

class Timer:
    def __init__(self):
        self._h = 0
    @property
    def h(self):
        return self._h
    @h.setter
    def h(self, v):
        if v < 0:
            raise ValueError("h phải >= 0")
        self._h = v

t = Timer()
t.h = 5
print(t.h)                         # 5
t.h = -1
# ValueError: h phải >= 0

Quy ước đặt tên: một dấu gạch dưới đầu tên (_h) nói "đây là chi tiết nội bộ, đừng đụng từ bên ngoài". Odoo dùng cùng quy ước cho method riêng như _compute_total.

Đối tượng chứa đối tượng

class Session:
    def __init__(self, name, hours):
        self.name, self.hours = name, hours

class Course2:
    def __init__(self, name):
        self.name = name
        self.sessions = []         # một khóa "có nhiều" buổi học

    def add_session(self, s):
        self.sessions.append(s)
        return self

    @property
    def total_hours(self):
        return sum(s.hours for s in self.sessions)

cc = Course2("Odoo").add_session(Session("1", 3)).add_session(Session("2", 4))
print(cc.total_hours, len(cc.sessions))     # 7 2

Một khóa học "có nhiều" buổi học: đó là quan hệ One2many ở series Odoo, được mô phỏng bằng một list thuộc tính. Phép sum(s.hours for s in self.sessions) chính là cách một compute method tính tổng giờ.

Class Python trở thành model Odoo như thế nào?

from odoo import fields, models

class VincCourse(models.Model):
    _name = 'vinc.course'
    _description = "Khóa học"

    name = fields.Char(required=True)             # thuộc tính của class
    duration_hours = fields.Integer()
    session_ids = fields.One2many('vinc.course.session', 'course_id')

    def action_publish(self):
        for course in self:                       # self là recordset, duyệt từng bản ghi
            course.is_published = True

Có hai điểm khác cần nhớ. Thứ nhất, bạn thường không viết __init__ cho model như ví dụ trên: khung ORM của models.Model lo việc tạo đối tượng (theo tài liệu, class được khởi tạo một lần cho mỗi database có cài module), bạn chỉ khai báo field. Thứ hai, trong method của model, self là recordset, nên bạn duyệt for course in self để làm việc với từng bản ghi (bài 3); mỗi lần lặp, course là recordset một phần tử. Tài liệu ORM cũng cảnh báo bạn không được khai báo một field và một method cùng tên trong một model vì khai báo sau sẽ ghi đè khai báo trước mà không có thông báo.

Thực hành: class Session và Course

  1. Chạy lại ví dụ Course2 và Session ở trên.
  2. Thêm property end_hour hoặc method remove_session(name) vào Course2.
  3. Thêm kiểm tra: add_session báo ValueError nếu hours <= 0.

Mục tiêu là làm quen với việc đưa logic vào method của class thay vì rải rác ở nhiều hàm: đúng thói quen bạn cần khi viết method cho model Odoo.

Lỗi hay gặp khi mới học

Course()
# TypeError: Course.__init__() missing 2 required positional arguments: 'name' and 'hours'

c.price_per_hour = 5
# AttributeError: property 'price_per_hour' of 'Course' object has no setter

x = Course("A", 1)
y = x                              # y là cùng đối tượng, không phải bản sao
y.name = "B"
print(x.name)                      # B
  • Thiếu tham số khi tạo đối tượng. Báo TypeError liệt kê các tham số bắt buộc còn thiếu.
  • List/dict ở cấp class. Dùng chung giữa mọi đối tượng; hãy khởi tạo trong __init__.
  • Tưởng phép gán sao chép đối tượng. y = x chỉ thêm một tên cho cùng đối tượng, sửa y là sửa x.
  • Quên self. Trong method, truy cập thuộc tính phải qua self.name; chỉ viết name là một biến khác hoặc gây lỗi.

Tổng kết

  • Class là khuôn, đối tượng là bản thể; __init__ khởi tạo, self là đối tượng hiện tại.
  • Dữ liệu riêng khởi tạo trong __init__; list/dict cấp class bị dùng chung.
  • @property cho giá trị tính toán dùng như thuộc tính; thêm setter để kiểm tra khi gán.
  • Model Odoo là class với field là thuộc tính; self là recordset nên luôn duyệt bằng for record in self.

Bài tiếp theo mở rộng class bằng kế thừa, super() và decorator, nền tảng của việc ghi đè method trong Odoo.

Câu hỏi thường gặp

self trong Python là gì? ▾
self là tham chiếu tới chính đối tượng đang gọi method. Nó luôn là tham số đầu tiên của method trong class và Python tự truyền vào khi bạn gọi, ví dụ c.publish() tương đương Course.publish(c).
Khác nhau giữa thuộc tính class và thuộc tính đối tượng? ▾
Thuộc tính khai báo trong thân class được mọi đối tượng dùng chung, còn thuộc tính gán qua self trong __init__ là của riêng từng đối tượng. List hay dict ở cấp class bị dùng chung nên cần khởi tạo trong __init__.
@property dùng để làm gì? ▾
Biến một method thành thuộc tính chỉ đọc được tính khi cần, như c.price_per_hour. Muốn kiểm tra giá trị lúc gán, thêm setter bằng @ten.setter.
self trong method của model Odoo khác gì self thông thường? ▾
Trong Odoo, self là một recordset, có thể chứa 0, 1 hoặc nhiều bản ghi, nên bạn duyệt for record in self để xử lý từng bản ghi thay vì coi nó là một đối tượng đơn lẻ.
