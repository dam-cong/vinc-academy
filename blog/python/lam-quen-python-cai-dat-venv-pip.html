Làm quen Python cho dev Odoo: cài đặt, venv và pip

Trước khi viết code Odoo, bạn cần một môi trường Python sạch và đúng phiên bản. Bài này hướng dẫn cài Python 3.12, chạy script, tạo môi trường ảo và quản lý thư viện bằng pip, với ví dụ từ dự án quản lý khóa học.

Cập nhật: 16/10/2026 9 phút đọc – lượt xem Đội ngũ Vinc Academy

Tóm tắt nhanh

Odoo 20 chạy trên Python 3.12 trở lên. Mỗi dự án nên có một môi trường ảo (venv) riêng và danh sách thư viện trong requirements.txt. Bạn kiểm tra phiên bản bằng python3 --version, tạo môi trường bằng python3 -m venv .venv, kích hoạt bằng source .venv/bin/activate rồi cài thư viện bằng python -m pip install -r requirements.txt. Bài này là bước đầu của series Python thực chiến: mọi ví dụ lấy từ dự án quản lý khóa học vinc_course quen thuộc.

Bạn sẽ viết Python ở đâu trong công việc Odoo?

Nếu bạn đã đọc series Odoo, bạn biết gần như mọi thứ ở tầng nghiệp vụ đều là Python: model, ORM, ràng buộc, controller, test, script tích hợp. Series này không dạy Python theo kiểu "thuộc hết cú pháp rồi mới làm", mà đi theo thứ tự bạn cần dùng khi làm việc, và mỗi bài chỉ ra khái niệm đó nằm ở đâu trong code Odoo.

Cài Python và kiểm tra phiên bản

Odoo 20 yêu cầu Python 3.12 trở lên (xem lại bài 2). Sau khi cài, kiểm tra bằng:

python3 --version
python3 -c "import sys; print(sys.version_info >= (3, 12))"

Lệnh thứ hai in True nếu phiên bản đủ mới, rất tiện để đặt trong script kiểm tra môi trường. Trình thông dịch thường nằm ở dạng /usr/local/bin/python3.12, nên bạn có thể gọi đích danh python3.12 khi máy có nhiều phiên bản. Trên Windows cài từ Microsoft Store thì có lệnh python3.12, còn nếu có bộ khởi chạy py.exe thì dùng lệnh py.

Bốn cách chạy Python

CáchLệnhDùng khi
Chế độ tương tácpython3Thử nhanh một biểu thức; dấu nhắc là >>>, thoát bằng Ctrl+D hoặc quit()

Khi chạy một file, tên file và các tham số phía sau được gom thành danh sách chuỗi trong sys.argv. Hãy thử với script nhỏ dưới đây:

course_info.py

import sys

course = "Odoo Developer Foundation"
hours = 24
print(f"Khóa học: {course} - {hours} giờ")
print("Tham số dòng lệnh:", sys.argv[1:])
$ python3 course_info.py abc 123
Khóa học: Odoo Developer Foundation - 24 giờ
Tham số dòng lệnh: ['abc', '123']

Đây chính là cơ chế odoo-bin dùng để đọc các tham số như -d, -u, --addons-path mà bạn đã gõ nhiều lần ở series Odoo.

Môi trường ảo (venv): mỗi dự án một "ngăn" riêng

Ứng dụng Python thường dùng thư viện ngoài thư viện chuẩn, và đôi khi cần đúng một phiên bản cụ thể. Nếu ứng dụng A cần thư viện bản 1.0 còn ứng dụng B cần bản 2.0, cài một trong hai sẽ làm ứng dụng kia hỏng. Giải pháp là môi trường ảo: một thư mục độc lập chứa một bản Python và các gói riêng của dự án. Với Odoo, điều này cho phép bạn giữ Odoo 20 và một dự án cũ chạy song song mà không đụng nhau.

cd ~/odoo-dev
python3 -m venv .venv            # tạo môi trường
source .venv/bin/activate        # kích hoạt (Linux/macOS)
# Windows: .venv\Scripts\activate
(.venv) $ python --version       # dấu nhắc có thêm (.venv)
(.venv) $ deactivate             # thoát khi xong
  • Lệnh venv tạo môi trường bằng đúng phiên bản Python đã chạy lệnh đó. Chạy bằng python3.12 thì môi trường là 3.12.
  • Tên thư mục phổ biến là .venv: dấu chấm giúp thư mục nằm gọn trong shell và không đụng với các file .env chứa biến môi trường.
  • Môi trường ảo không đưa vào Git, coi là thứ dùng một lần: dễ xóa và tạo lại, không sao chép sang chỗ khác. Hãy thêm .venv/ vào .gitignore.
  • Đừng đặt mã dự án bên trong thư mục môi trường ảo.

Thực tế trên Debian/Ubuntu

Ở một số bản Debian/Ubuntu, lệnh python3 -m venv báo môi trường chưa tạo được vì thiếu ensurepip và yêu cầu cài gói python3-venv (ví dụ sudo apt install python3-venv). Cài gói đó rồi tạo lại môi trường là xong.

Quản lý thư viện bằng pip

Khi môi trường ảo đã kích hoạt, dùng python -m pip để cài thư viện từ Python Package Index. Viết python -m pip thay vì pip để chắc chắn gói được cài cho đúng bản Python đang dùng.

LệnhTác dụng
python -m pip install requestsCài bản mới nhất của một gói
python -m pip install requests==2.6.0Cài đúng một phiên bản
python -m pip install --upgrade requestsNâng cấp lên bản mới nhất
python -m pip uninstall requestsGỡ gói
python -m pip list / show requestsLiệt kê gói đã cài / xem thông tin một gói
python -m pip freeze > requirements.txtGhi danh sách gói kèm phiên bản ra file
python -m pip install -r requirements.txtCài mọi gói trong file

Quy ước requirements.txt chính là thứ bạn dùng khi cài Odoo từ source: mã nguồn Odoo kèm sẵn file này, và bước "cài thư viện phụ thuộc" ở bài 2 chỉ là pip install -r requirements.txt trong môi trường ảo. Với module tự viết cần thêm thư viện ngoài, bạn khai báo thêm trong external_dependencies của manifest (bài 3).

Thực hành: thiết lập môi trường cho dự án vinc_course

  1. Tạo thư mục dự án và môi trường ảo: mkdir vinc-tools && cd vinc-tools && python3 -m venv .venv.
  2. Kích hoạt: source .venv/bin/activate, kiểm tra dấu nhắc có (.venv).
  3. Cài thư viện: python -m pip install requests (dùng ở bài 13).
  4. Ghi lại: python -m pip freeze > requirements.txt.
  5. Lưu file course_info.py ở trên và chạy python course_info.py abc.

Kết quả mong đợi: dấu nhắc có (.venv), pip list thấy requests, file requirements.txt có vài dòng dạng tên==phiên_bản, và script in hai dòng như ví dụ.

Lỗi hay gặp khi mới bắt đầu

  • Quên kích hoạt môi trường ảo rồi mới cài thư viện. Khi môi trường được kích hoạt, python và pip sẽ trỏ vào môi trường đó; nếu chưa, bạn cài vào Python của hệ thống và Odoo trong venv vẫn thiếu thư viện. Hãy nhìn dấu nhắc có (.venv) trước khi chạy pip.
  • Tạo venv bằng sai phiên bản Python. venv dùng đúng phiên bản của lệnh đã tạo ra nó. Nếu máy có Python 3.10 làm mặc định mà bạn chạy python3 -m venv, Odoo 20 sẽ không đủ điều kiện. Hãy chạy python3.12 -m venv .venv (hoặc bản mới hơn) và kiểm tra bằng python --version.
  • Sao chép cả thư mục venv sang máy khác. Môi trường ảo không phải thứ để di chuyển. Hãy tạo mới và cài từ requirements.txt.

Tổng kết

  • Odoo 20 cần Python 3.12+; kiểm tra bằng python3 --version.
  • Chạy Python qua chế độ tương tác, file script, -c hoặc -m; tham số nằm trong sys.argv.
  • Mỗi dự án một .venv (không đưa vào Git), cài thư viện bằng python -m pip.
  • requirements.txt giúp tái tạo môi trường trên máy khác.

Bài tiếp theo bắt đầu viết code thật: biến, kiểu dữ liệu và chuỗi, với mã khóa học và thông báo log làm ví dụ.

Câu hỏi thường gặp

Odoo 20 cần phiên bản Python nào? ▾
Odoo 20 yêu cầu Python 3.12 trở lên. Bạn có thể kiểm tra bằng python3 --version, hoặc chạy python3 -c với biểu thức so sánh sys.version_info để in True khi phiên bản đủ mới.
Vì sao mỗi dự án nên có môi trường ảo riêng? ▾
Mỗi môi trường ảo là một thư mục độc lập chứa một bản Python và các gói riêng, nên dự án này cần thư viện bản 1.0 còn dự án kia cần bản 2.0 vẫn không xung đột.
Có nên đưa thư mục venv vào Git không? ▾
Không. Môi trường ảo là thứ dùng một lần, dễ xóa và tạo lại, không được sao chép sang nơi khác. Hãy thêm vào .gitignore và dùng requirements.txt để tái tạo.
Khác nhau giữa pip install và python -m pip install? ▾
Cả hai đều cài gói, nhưng python -m pip đảm bảo gói được cài cho đúng bản Python bạn đang chạy, nên an toàn hơn khi máy có nhiều phiên bản.
