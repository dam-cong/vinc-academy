Python: biến, kiểu dữ liệu, chuỗi và f-string cho dev Odoo

Mọi dòng code đều bắt đầu từ giá trị và cách đặt tên cho chúng. Bài này giải thích biến, các kiểu dữ liệu cơ bản và xử lý chuỗi bằng ví dụ sinh mã khóa học, đồng thời chỉ ra chúng xuất hiện ở đâu trong field Odoo.

Cập nhật: 16/10/2026 10 phút đọc – lượt xem Đội ngũ Vinc Academy

Tóm tắt nhanh

Biến trong Python chỉ là cái tên trỏ tới một giá trị; kiểu dữ liệu nằm ở giá trị chứ không ở biến. Bốn kiểu cơ bản bạn dùng hằng ngày là int, float, str và bool, cộng với None cho "chưa có giá trị". Định dạng chuỗi hiện đại nhất là f-string: f"{ma}-{nam}". Trong Odoo, các kiểu này tương ứng trực tiếp với fields.Integer, Float, Char, Boolean.

Biến: đặt tên cho một giá trị

Bạn tạo biến bằng cách gán: không cần khai báo kiểu. Cùng một tên có thể được gán lại cho giá trị kiểu khác, và hàm type() cho biết giá trị hiện tại thuộc kiểu nào:

course_name = "Odoo Developer Foundation"
hours = 24
price = 4500000.0
is_published = True
description = None

print(type(course_name), type(hours), type(price), type(is_published), type(description))
# <class 'str'> <class 'int'> <class 'float'> <class 'bool'> <class 'NoneType'>

Quy ước đặt tên trong cộng đồng Python (và Odoo) là snake_case cho biến, hàm; CamelCase cho class. Tên phân biệt hoa thường, không bắt đầu bằng số. Đây cũng là lý do bạn thấy is_published, duration_hours trong model vinc.course: mỗi field của model chính là một "biến" của bản ghi.

Field trống trong Odoo là False, không phải None

Ở phía Odoo, tài liệu về file dữ liệu cho biết khi không cung cấp giá trị cho một field, một giá trị False ngầm được đặt cho nó. Vì vậy khi đọc field Char chưa nhập, đừng dùng is None để kiểm tra; hãy dùng điều kiện "có giá trị hay không" như if not course.name:.

Python coi những giá trị sau là "sai" trong điều kiện: False, None, số 0, chuỗi rỗng và danh sách rỗng. Mọi giá trị khác là "đúng". Nhờ đó if description: vừa chặn None vừa chặn chuỗi rỗng:

print(bool(""), bool("a"), bool(0), bool([]), bool(None))
# False True False False False

Số và phép tính

print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)
# 3.5 3 1 1024

/ luôn trả số thực, // chia lấy phần nguyên, % lấy phần dư và ** là lũy thừa. Ví dụ đổi giờ ra buổi học 8 giờ: hours // 8 là số buổi tròn, hours % 8 là số giờ lẻ.

Số thực lưu dưới dạng nhị phân nên có sai số nhỏ, đây là chuyện của mọi ngôn ngữ chứ không riêng Python:

print(0.1 + 0.2, 0.1 + 0.2 == 0.3)
# 0.30000000000000004 False

import math
print(math.isclose(0.1 + 0.2, 0.3))
# True

Đây là lý do tài liệu Odoo dặn khi so sánh số thực phải dùng float_compare() và float_is_zero() thay vì == (bài 8 của series Odoo). Với tiền tệ, hãy dùng field Monetary hoặc làm tròn đúng độ chính xác.

Chuỗi: thứ bạn xử lý nhiều nhất

Chuỗi viết trong dấu nháy đơn hoặc kép; chuỗi nhiều dòng dùng ba dấu nháy. Chuỗi là bất biến: các hàm xử lý luôn trả chuỗi mới chứ không sửa chuỗi cũ.

Thao tácVí dụKết quả

Định dạng chuỗi: f-string, %, format()

F-string (chuỗi có tiền tố f) cho phép nhúng biểu thức vào trong dấu ngoặc nhọn và thêm định dạng sau dấu hai chấm:

prefix, year, seq = "ODO", 2026, 7
print(f"{prefix}-{year}-{seq:03d}")        # ODO-2026-007
price, hours = 4500000.0, 24
print(f"{price:,.0f} VND", f"{hours / 8:.1f} ngày")   # 4,500,000 VND 3.0 ngày

Hai kiểu cũ hơn bạn vẫn gặp trong mã Odoo: toán tử % (tài liệu Odoo viết self.message = "Dear %s" % (self.partner_id.name or "")) và "{} - {}".format(...). Chúng cho cùng kết quả:

print("Dear %s" % "Hiền", "%d giờ" % 24)    # Dear Hiền 24 giờ
print("{} - {}".format("ODO-F", hours))     # ODO-F - 24

So sánh và toán tử logic

Điều kiện (bài sau) được dựng từ phép so sánh và and, or, not. Kết quả luôn là True hoặc False:

hours = 24
level = "beginner"
print(hours > 20, hours == 24, hours != 24, 10 <= hours < 30)
# True True False True
print(level == "beginner" and hours >= 24, level == "advanced" or hours > 100, not hours > 100)
# True False True
print("odoo" in "odoo developer", "Odoo" in ["odoo", "python"], 24 in [8, 24])
# True False True
  • Có thể viết so sánh chuỗi như 10 <= hours < 30, đúng như cách bạn viết trong toán học.
  • in kiểm tra một chuỗi con nằm trong chuỗi hay một phần tử nằm trong danh sách. Chú ý so sánh chuỗi phân biệt hoa thường: "python" == "Python" là False, nên người ta thường chuẩn hóa bằng .lower() trước khi so.
  • Với None, hãy dùng is None / is not None thay vì == None. Cả hai thường cho cùng kết quả, nhưng is là cách viết chuẩn của Python và rõ ý hơn.

Những phép so sánh này chính là nền của domain trong Odoo: [('hours', '>', 20), ('level', '=', 'beginner')] là cách viết "dữ liệu" của cùng một điều kiện, ORM sẽ dịch thành SQL.

Dữ liệu đọc từ file CSV hay form thường là chuỗi, nên bạn cần int(), float() trước khi tính toán. Chuỗi không hợp lệ gây ra ValueError (bài 10 sẽ xử lý lỗi này).

Thực hành: sinh mã và slug cho khóa học

Viết script nhận tên khóa học thô và số thứ tự, trả về mã khóa học và slug thân thiện URL:

def make_code(prefix, year, seq):
    return f"{prefix.upper()}-{year}-{seq:03d}"

def make_slug(name):
    return name.strip().lower().replace(" ", "-")

print(make_code("odo", 2026, 7))
print(make_slug("  Odoo Developer Foundation  "))
# ODO-2026-007
# odoo-developer-foundation

Thử thay đổi: thêm kiểm tra if not name: để báo lỗi khi tên rỗng. Đây đúng là kiểu logic bạn đặt trong create() hoặc một compute method để tự sinh mã khóa học.

Lỗi hay gặp khi mới học

  • Cộng chuỗi với số. "5" + 3 báo TypeError: can only concatenate str (not "int") to str. Hãy ép kiểu (int("5") + 3) hoặc dùng f-string (f"{5}{3}").
  • Sửa một ký tự trong chuỗi. course_name[0] = "x" báo TypeError: 'str' object does not support item assignment vì chuỗi bất biến. Hãy tạo chuỗi mới bằng replace() hoặc cắt lát.
  • So sánh số thực bằng ==. 0.1 + 0.2 == 0.3 là False. Dùng math.isclose() trong Python thuần, hoặc float_compare() trong Odoo.
  • Ép chuỗi không phải số. int("abc") báo ValueError: invalid literal for int() with base 10: 'abc'. Hãy kiểm tra hoặc bắt lỗi trước khi ép.

Tổng kết

  • Biến là tên trỏ tới giá trị; dùng snake_case; type() cho biết kiểu.
  • Bốn kiểu cơ bản int, float, str, bool cùng None tương ứng các field Odoo.
  • Chuỗi bất biến; dùng strip, split, join, replace và f-string để xử lý.
  • Không so sánh số thực bằng ==; dữ liệu đọc ra thường là chuỗi nên cần ép kiểu.

Bài tiếp theo thêm "bộ não" cho chương trình: điều kiện và vòng lặp, nền tảng của for record in self.

Câu hỏi thường gặp

Biến trong Python khác gì so với ngôn ngữ khác? ▾
Python không cần khai báo kiểu; biến chỉ là cái tên trỏ tới một giá trị và có thể được gán lại cho giá trị kiểu khác. Hàm type cho biết giá trị hiện tại thuộc kiểu nào.
F-string là gì và vì sao nên dùng? ▾
F-string là chuỗi có tiền tố f cho phép nhúng biểu thức trong dấu ngoặc nhọn và thêm định dạng sau dấu hai chấm, ví dụ f"{seq:03d}". Nó ngắn gọn và dễ đọc hơn toán tử % hay format.
Vì sao 0.1 + 0.2 khác 0.3? ▾
Số thực được lưu dưới dạng nhị phân nên có sai số nhỏ. Hãy so sánh bằng math.isclose trong Python, hoặc float_compare và float_is_zero trong Odoo, thay vì dùng dấu bằng kép.
Field Char trống trong Odoo là None hay False? ▾
Theo tài liệu Odoo về file dữ liệu, khi không cung cấp giá trị cho field thì một giá trị False ngầm được đặt. Hãy kiểm tra bằng if not value thay vì is None.
