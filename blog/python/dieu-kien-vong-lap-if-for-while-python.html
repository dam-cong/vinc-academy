Python: điều kiện và vòng lặp if, for, while, match

Điều kiện và vòng lặp là cách chương trình đưa ra quyết định và xử lý hàng loạt dữ liệu. Bài này đi qua if, for, while, match bằng danh sách khóa học, và chỉ ra vì sao for record in self trong Odoo chính là vòng lặp for quen thuộc.

Cập nhật: 16/10/2026 10 phút đọc Đội ngũ Vinc Academy

Tóm tắt nhanh

Điều kiện (if/elif/else) quyết định đoạn code nào chạy, vòng lặp (for, while) lặp lại một khối code. Python dùng thụt dòng và dấu hai chấm để đánh dấu khối. Vòng lặp bạn dùng nhiều nhất là for item in danh_sach, và đó chính là hình dạng của for record in self trong mọi method của model Odoo. match (từ Python 3.10) hữu ích khi một giá trị có nhiều nhánh xử lý.

Điều kiện: if, elif, else

Mỗi nhánh có một dấu hai chấm, và khối code bên dưới phải thụt vào (quy ước 4 dấu cách). Python kiểm tra lần lượt từ trên xuống và chạy nhánh đầu tiên đúng. Ví dụ phân loại độ dài khóa học theo số giờ:

def level_of(hours):
    if hours >= 24:
        return "dài"
    elif hours >= 12:
        return "vừa"
    else:
        return "ngắn"

print(level_of(24), level_of(16), level_of(8))
# dài vừa ngắn

Bạn đã biết các phép so sánh và and/or/not ở bài trước. Với danh sách, chuỗi hay số 0, bạn có thể viết thẳng if danh_sach: để kiểm tra "có phần tử" mà không cần so sánh độ dài.

Điều kiện một dòng và kiểm tra sớm

Khi chỉ cần chọn giữa hai giá trị, dùng biểu thức điều kiện thay cho cả khối if/else. Cách viết này xuất hiện rất nhiều trong compute method của Odoo, đặc biệt để tránh chia cho 0:

hours = 24
label = "dài" if hours >= 24 else "ngắn"          # dài

price, duration = 4500000.0, 0
price_per_hour = price / duration if duration else 0.0   # 0.0, không lỗi chia cho 0

Với logic kiểm tra dữ liệu, thói quen tốt là kiểm tra sớm và thoát sớm thay vì lồng nhiều tầng if. Mỗi điều kiện lỗi trả về ngay, và đường chạy thành công nằm cuối cùng, thẳng hàng:

def check(course):
    if not course["name"]:
        return "Thiếu tên"
    if course["hours"] <= 0:
        return "Giờ học phải lớn hơn 0"
    if not course["published"]:
        return "Chưa xuất bản"
    return "OK"

print(check({"name": "", "hours": 8, "published": True}))     # Thiếu tên
print(check({"name": "Git", "hours": 0, "published": True}))  # Giờ học phải lớn hơn 0
print(check({"name": "Git", "hours": 8, "published": True}))  # OK

Cấu trúc này giống hệt một method constraint trong Odoo, chỉ khác ở chỗ thay vì return chuỗi, Odoo raise ValidationError(...) (bài 10). Một mẫu khác bạn sẽ gặp là kiểm tra quyền trước khi làm việc nhạy cảm, như ví dụ trong tài liệu bảo mật Odoo: if self.state == "draft" and self.env.user.has_group('base.manager'):.

Vòng lặp for: duyệt từng phần tử

Chúng ta dùng danh sách các khóa học làm dữ liệu mẫu (mỗi khóa là một dict, sẽ học kỹ ở bài 4):

courses = [
    {"code": "ODO-F", "name": "Odoo cơ bản", "hours": 24, "published": True},
    {"code": "PY-F", "name": "Python cơ bản", "hours": 16, "published": True},
    {"code": "GIT-T", "name": "Git cho nhóm", "hours": 8, "published": False},
]

total = 0
for course in courses:
    if not course["published"]:
        continue
    total += course["hours"]
print("Tổng giờ đã xuất bản:", total)
# Tổng giờ đã xuất bản: 40

Mỗi vòng, biến course nhận một phần tử. continue bỏ qua phần còn lại của vòng hiện tại, break thoát hẳn vòng lặp. Trong Odoo, cùng hình dạng đó xuất hiện ở bài computed field:

for course in self:
    course.session_count = len(course.session_ids)

Ở đây self là recordset (một tập bản ghi) và vòng lặp trao từng bản ghi vào course. Vì vậy bạn luôn thấy for record in self ở đầu các method compute, constraint hay action_*.

Một vài chi tiết hay bị bỏ sót

  • Biến vòng lặp vẫn tồn tại sau vòng lặp. Sau for course in courses: pass, course vẫn giữ phần tử cuối cùng. Tránh phụ thuộc vào điều này, và đặt tên biến vòng lặp khác với biến bên ngoài để khỏi vô tình ghi đè.
  • pass là lệnh "không làm gì", dùng khi cú pháp đòi một khối nhưng bạn chưa viết nội dung (ví dụ method khung đang chờ viết).
  • Không dùng range(len(ds)) để lấy chỉ số. Nó chạy đúng nhưng dài dòng, hãy dùng enumerate như bảng trên.
  • any() và all() thay cho vòng lặp kiểm tra. any(c["hours"] > 20 for c in courses) trả True nếu có ít nhất một khóa dài hơn 20 giờ; all(...) chỉ trả True khi mọi khóa đều thỏa. Bạn đã thấy any(course.is_published for course in self) trong ví dụ chặn xóa ở series Odoo.
  • while True kết hợp break là mẫu quen thuộc khi bạn cần chạy ít nhất một lần rồi mới biết có tiếp tục hay không.

while, break và else của vòng lặp

while lặp khi điều kiện còn đúng, hợp với trường hợp không biết trước số lần (ví dụ thử gọi API lại cho tới khi thành công):

n = 3
while n > 0:
    print("còn", n)
    n -= 1
# còn 3
# còn 2
# còn 1

Python còn có một đặc điểm thú vị: vòng lặp có thể có nhánh else, chạy khi vòng lặp kết thúc bình thường (không bị break). Rất hợp để tìm kiếm:

for code in ("ODO-F", "XYZ"):
    for course in courses:
        if course["code"] == code:
            print("Tìm thấy", code)
            break
    else:
        print("Không thấy", code)
# Tìm thấy ODO-F
# Không thấy XYZ

match: nhiều nhánh theo giá trị

Từ Python 3.10, lệnh match so khớp một giá trị với các mẫu case. Dấu | gộp nhiều giá trị, _ là nhánh mặc định. Ví dụ đổi mã trạng thái HTTP của API (bài 13) thành thông báo:

def status_message(code):
    match code:
        case 200:
            return "OK"
        case 401 | 403:
            return "Không có quyền"
        case 404:
            return "Không tìm thấy"
        case _:
            return "Lỗi khác"

print([status_message(c) for c in (200, 403, 404, 500)])
# ['OK', 'Không có quyền', 'Không tìm thấy', 'Lỗi khác']

Odoo 20 chạy Python 3.12+ nên bạn dùng được match trong module mới. Tuy vậy, trong code Odoo hiện có bạn vẫn gặp chủ yếu chuỗi if/elif, nên cần đọc được cả hai.

Thực hành: báo cáo nhanh danh sách khóa học

Viết đoạn code in từng khóa kèm độ dài, bỏ qua khóa chưa xuất bản, rồi in tổng:

total = 0
for course in courses:
    if not course["published"]:
        continue
    print(course["code"], level_of(course["hours"]))
    total += course["hours"]
print("Tổng:", total)
# ODO-F dài
# PY-F vừa
# Tổng: 40

Thử thay continue bằng break để thấy sự khác biệt: vòng lặp dừng hẳn ngay ở khóa chưa xuất bản đầu tiên.

Lỗi hay gặp khi mới học

  • Thụt dòng sai hoặc thiếu. Quên thụt khối sau if báo IndentationError: expected an indented block after 'if' statement on line 2. Hãy dùng 4 dấu cách và đừng trộn tab với dấu cách.
  • Quên dấu hai chấm. if hours > 20 thiếu : báo SyntaxError: expected ':'.
  • Sửa danh sách khi đang duyệt nó. Tài liệu Python cảnh báo việc thay đổi tập hợp trong lúc lặp rất khó làm đúng. Hãy duyệt trên bản sao (for x in nums[:]:) hoặc tạo danh sách mới. Với danh sách [1, 2, 3, 4], xóa số chẵn trên bản sao cho đúng kết quả [1, 3].
  • Vòng while không bao giờ dừng. Luôn có điều kiện thay đổi trong thân vòng lặp (như n -= 1), hoặc một break rõ ràng.

Tổng kết

  • if/elif/else chạy nhánh đầu tiên đúng; khối code nhận biết bằng dấu hai chấm và thụt dòng.
  • for item in iterable là vòng lặp chính; enumerate, zip, .items() giúp lặp gọn hơn.
  • break, continue, else của vòng lặp điều khiển luồng; match xử lý nhiều nhánh theo giá trị.
  • for record in self của Odoo chính là vòng lặp for trên recordset.

Bài tiếp theo giới thiệu bốn cấu trúc dữ liệu bạn dùng liên tục: list, tuple, set và dict.

Câu hỏi thường gặp

for record in self trong Odoo là gì? ▾
self là một recordset, tức tập hợp các bản ghi. Vòng lặp for duyệt qua từng bản ghi và gán vào biến record, nên bạn xử lý được cả khi method được gọi trên nhiều bản ghi cùng lúc.
Khác nhau giữa break và continue? ▾
continue bỏ qua phần còn lại của vòng lặp hiện tại và chuyển sang phần tử kế tiếp, còn break thoát hẳn khỏi vòng lặp.
Nhánh else của vòng lặp for chạy khi nào? ▾
Nhánh else chạy khi vòng lặp kết thúc bình thường, tức không bị break. Nó rất hợp cho bài toán tìm kiếm: nếu không tìm thấy thì chạy else.
Khi nào dùng match thay cho if/elif? ▾
Khi một giá trị có nhiều nhánh xử lý rõ ràng, ví dụ mã trạng thái HTTP. match có từ Python 3.10, nên dùng được trong module Odoo 20 chạy Python 3.12 trở lên.
