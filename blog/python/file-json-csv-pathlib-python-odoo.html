Python đọc ghi file, JSON, CSV và pathlib cho dev Odoo

Nhập xuất dữ liệu là công việc thường xuyên của dev Odoo: file CSV, phản hồi API dạng JSON, file cấu hình. Bài này dạy pathlib, open, json, csv, configparser bằng ví dụ xuất nhập danh sách khóa học, kèm các lỗi encoding hay gặp.

Cập nhật: 16/10/2026 16 phút đọc Đội ngũ Vinc Academy

Tóm tắt nhanh

Dùng pathlib.Path cho đường dẫn, with open(..., encoding="utf-8") để đọc ghi file, json cho dữ liệu lồng nhau và csv cho bảng. Luôn chỉ định encoding="utf-8" (và newline="" với csv). Mọi giá trị đọc từ CSV đều là chuỗi nên phải ép kiểu. Trong công việc Odoo, bạn gặp ba định dạng này liên tục: CSV cho dữ liệu và phân quyền (ir.model.access.csv), JSON cho API, và file cấu hình odoo.conf.

Đường dẫn với pathlib

Thay vì nối chuỗi đường dẫn bằng tay, dùng pathlib.Path: nó xử lý đúng dấu phân cách trên mọi hệ điều hành và có sẵn các thao tác hay dùng:

from pathlib import Path

base = Path("data")
base.mkdir(parents=True, exist_ok=True)       # tạo thư mục, không lỗi nếu đã có
p = base / "courses.json"                      # toán tử / nối đường dẫn
print(p, p.suffix, p.stem, p.parent, p.exists())
# data/courses.json .json courses data False

(base / "a.txt").write_text("ODO-F\nPY-F\n", encoding="utf-8")
print((base / "a.txt").read_text(encoding="utf-8").splitlines())   # ['ODO-F', 'PY-F']
print(sorted(x.name for x in base.glob("*.txt")))                  # ['a.txt']

Đường dẫn tương đối như "data/courses.json" được tính theo thư mục hiện tại khi chạy chương trình, không phải thư mục chứa file script. Muốn đường dẫn ổn định, hãy tính từ Path(__file__).resolve().parent.

Đọc và ghi file text

with open(base / "a.txt", encoding="utf-8") as f:     # chế độ mặc định "r" (đọc)
    for line in f:                                     # duyệt từng dòng, tiết kiệm bộ nhớ
        print(line.strip(), end=" ")                   # ODO-F PY-F
print()

with open(base / "a.txt", "a", encoding="utf-8") as f:  # "a": ghi nối thêm vào cuối
    f.write("GIT-T\n")
print((base / "a.txt").read_text(encoding="utf-8").splitlines())   # ['ODO-F', 'PY-F', 'GIT-T']
  • Chế độ "r" đọc (mặc định), "w" ghi và xóa nội dung cũ, "a" ghi nối thêm vào cuối.
  • Luôn thêm encoding="utf-8", nhất là khi dữ liệu có tiếng Việt, để kết quả giống nhau trên mọi máy.
  • Duyệt for line in f đọc từng dòng, tiết kiệm bộ nhớ với file lớn, còn read() đọc cả file một lần.
  • Luôn dùng with (bài 10) để file tự đóng.

File nhị phân và base64

Ảnh, PDF, file nén là dữ liệu nhị phân: đọc ra bytes, không phải chuỗi. Khi cần đưa chúng qua JSON hay lưu trong field của Odoo, người ta mã hóa thành văn bản bằng base64. Tài liệu Odoo về file dữ liệu cũng có kiểu base64 để nạp nội dung file (như hình ảnh) vào attachment, và các field nhị phân của Odoo đọc ra dạng chuỗi base64 qua read():

import base64

img = Path("a.bin")
img.write_bytes(bytes([0, 1, 2, 255]))         # ghi nhị phân: bytes, không phải str
raw = img.read_bytes()
print(raw, len(raw))                           # b'\x00\x01\x02\xff' 4

b64 = base64.b64encode(raw).decode("ascii")    # bytes -> chuỗi base64 để gửi qua JSON
print(b64, base64.b64decode(b64) == raw)       # AAEC/w== True

File và thư mục tạm

Khi viết test (bài 14) hoặc xử lý trung gian, bạn không muốn để lại file rác. Module tempfile tạo thư mục hoặc file tạm và tự dọn khi ra khỏi khối with:

import tempfile

with tempfile.TemporaryDirectory() as tmp:     # thư mục tạm, tự xóa khi ra khỏi khối with
    t = Path(tmp) / "t.txt"
    t.write_text("tạm", encoding="utf-8")
    print(t.exists())                          # True
print(t.exists())                              # False

Đọc JSON từ API một cách an toàn

Dữ liệu JSON từ bên ngoài không đảm bảo có đủ khóa. Dùng .get() với giá trị mặc định ở mỗi tầng có thể vắng, rồi chuyển sang đối tượng có kiểu (như @dataclass ở bài 8) để phần còn lại của code làm việc với dữ liệu sạch. Đây là ranh giới hợp lý để kiểm tra và ép kiểu:

import json
from dataclasses import dataclass

payload = json.loads('{"data": [{"code": "ODO-F", "hours": 24, "extra": {"x": 1}}, {"code": "PY-F"}]}')

for item in payload.get("data", []):
    print(item["code"], item.get("hours", 0), item.get("extra", {}).get("x"))
# ODO-F 24 1
# PY-F 0 None

@dataclass
class CourseRow:
    code: str
    hours: int = 0

    @classmethod
    def from_dict(cls, d):
        return cls(code=d["code"].strip().upper(), hours=int(d.get("hours", 0)))

print([CourseRow.from_dict(i) for i in payload["data"]])
# [CourseRow(code='ODO-F', hours=24), CourseRow(code='PY-F', hours=0)]

So sánh pathlib với os.path cũ hơn: os.path.join("data", "a.txt") trả chuỗi, còn Path("data") / "a.txt" trả đối tượng có sẵn .exists(), .read_text()... Code mới nên ưu tiên pathlib, nhưng bạn vẫn đọc được os.path trong mã cũ vì nhiều hàm chấp nhận cả hai kiểu.

JSON: dữ liệu lồng nhau

JSON là định dạng văn bản mô tả đối tượng, danh sách, chuỗi, số, boolean và null. Nó tương ứng trực tiếp với dict, list, str, int/float, bool và None của Python (bài 4), nên là định dạng của hầu hết API.

import json

courses = [
    {"code": "ODO-F", "name": "Odoo cơ bản", "hours": 24, "published": True, "price": None},
    {"code": "PY-F", "name": "Python cơ bản", "hours": 16, "published": False, "price": 1500000.5},
]
text = json.dumps(courses, ensure_ascii=False, indent=2)    # đối tượng -> chuỗi JSON
(base / "courses.json").write_text(text, encoding="utf-8")

back = json.loads((base / "courses.json").read_text(encoding="utf-8"))   # chuỗi -> đối tượng
print(back == courses, back[0]["published"], back[0]["price"])   # True True None

print(json.dumps({"a": True, "b": None}))             # {"a": true, "b": null}
print(json.dumps("tiếng Việt"))                       # "ti\u1ebfng Vi\u1ec7t"
print(json.dumps("tiếng Việt", ensure_ascii=False))   # "tiếng Việt"

with open(base / "out.json", "w", encoding="utf-8") as f:
    json.dump(courses, f, ensure_ascii=False)         # dump/load làm việc trực tiếp với file
  • dumps/loads làm việc với chuỗi; dump/load làm việc trực tiếp với file.
  • ensure_ascii=False giữ nguyên tiếng Việt thay vì đổi thành \uXXXX; indent=2 in đẹp.
  • True/None trở thành true/null trong JSON, rồi quay về đúng khi đọc lại.
  • JSON chuẩn dùng dấu nháy kép; dấu nháy đơn là lỗi.
import datetime
json.dumps({"when": datetime.date(2026, 10, 16)})
# TypeError: Object of type date is not JSON serializable

print(json.dumps({"when": datetime.date(2026, 10, 16)}, default=str))   # {"when": "2026-10-16"}

json.loads("{'a': 1}")
# json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)

Ngày giờ không tự chuyển được sang JSON; hãy chuyển thành chuỗi bằng default=str hoặc định dạng riêng (bài 12). Bạn đã thấy cách này trong tài liệu API ngoài của Odoo, nơi một đoạn mã minh họa trả về json.dumps(records.ids) và json.dumps(names).

CSV: dữ liệu dạng bảng

import csv

csv_path = base / "courses.csv"
with open(csv_path, "w", encoding="utf-8", newline="") as f:     # newline="" bắt buộc với csv
    w = csv.DictWriter(f, fieldnames=["code", "name", "hours"])
    w.writeheader()
    for c in courses:
        w.writerow({k: c[k] for k in ("code", "name", "hours")})
    w.writerow({"code": "X,Y", "name": 'Có "dấu nháy"', "hours": 8})   # dấu phẩy và nháy tự được bọc

print(csv_path.read_text(encoding="utf-8"))
# code,name,hours
# ODO-F,Odoo cơ bản,24
# PY-F,Python cơ bản,16
# "X,Y","Có ""dấu nháy""",8

with open(csv_path, encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))                # mỗi dòng là một dict theo tiêu đề cột
print(rows[0])            # {'code': 'ODO-F', 'name': 'Odoo cơ bản', 'hours': '24'}
print(type(rows[0]["hours"]))   # <class 'str'>   <- mọi giá trị đọc ra đều là chuỗi!
print(sum(int(r["hours"]) for r in rows))   # 48
with open(csv_path, encoding="utf-8", newline="") as f:
    r = csv.reader(f)                  # dòng là list, không có tên cột
    header = next(r)                   # lấy dòng tiêu đề
    print(header, next(r))
# ['code', 'name', 'hours'] ['ODO-F', 'Odoo cơ bản', '24']
  • csv.DictWriter/DictReader làm việc theo tên cột nên dễ đọc hơn csv.writer/reader làm việc theo vị trí.
  • Mở file CSV với newline="" để module csv tự xử lý xuống dòng đúng cách.
  • Giá trị chứa dấu phẩy hay dấu nháy được tự động bọc ("X,Y") khi ghi và tách đúng khi đọc.
  • Mọi ô đọc ra đều là chuỗi: "24" không phải 24, phải int() trước khi tính.

File cấu hình kiểu odoo.conf

File odoo.conf có dạng ini: các mục trong ngoặc vuông ([options]) và dòng khóa = giá_trị. Module configparser đọc được định dạng này:

import configparser

Path("odoo.conf").write_text(
    "[options]\nadmin_passwd = secret\ndb_host = 127.0.0.1\nworkers = 5\n", encoding="utf-8")

cp = configparser.ConfigParser()
cp.read("odoo.conf", encoding="utf-8")
print(cp["options"]["db_host"])                       # 127.0.0.1
print(cp.getint("options", "workers"))                # 5
print(cp.get("options", "dbfilter", fallback="(none)"))   # (none)

fallback cho giá trị mặc định khi khóa vắng. Bạn có thể dùng chính cách này để viết script kiểm tra cấu hình production trước khi triển khai (bài 14 của series Odoo): đọc workers, dbfilter, list_db rồi cảnh báo nếu thiếu.

Thực hành: xuất và nhập danh sách khóa học

def export_courses(courses, path):
    with open(path, "w", encoding="utf-8", newline="") as f:
        w = csv.DictWriter(f, fieldnames=["code", "name", "hours"])
        w.writeheader()
        for c in courses:
            w.writerow({k: c[k] for k in ("code", "name", "hours")})

def import_courses(path):
    ok, errors = [], []
    with open(path, encoding="utf-8", newline="") as f:
        for n, row in enumerate(csv.DictReader(f), start=2):     # dòng 1 là tiêu đề
            try:
                ok.append({"code": row["code"].strip().upper(), "hours": int(row["hours"])})
            except (KeyError, ValueError) as e:
                errors.append(f"dòng {n}: {e}")
    return ok, errors

export_courses(courses, base / "export.csv")
(base / "export.csv").open("a", encoding="utf-8", newline="").write("BAD,Hỏng,abc\n")
print(import_courses(base / "export.csv"))
# ([{'code': 'ODO-F', 'hours': 24}, {'code': 'PY-F', 'hours': 16}], ["dòng 4: invalid literal for int() with base 10: 'abc'"])

Hàm import_courses dùng lại mẫu gom dòng tốt/dòng lỗi ở bài 10, kèm số dòng để người dùng biết sửa ở đâu. Đây là phần lõi của script nhập dữ liệu vào Odoo ở bài 14.

Lỗi hay gặp khi mới học

open(base / "nope.txt").read()
# FileNotFoundError: [Errno 2] No such file or directory: 'data/nope.txt'

(base / "vn.txt").write_text("Tiếng Việt", encoding="utf-8")
open(base / "vn.txt", encoding="ascii").read()
# UnicodeDecodeError: 'ascii' codec can't decode byte 0xe1 in position 2: ordinal not in range(128)

# CSV cho Excel: dùng utf-8-sig để có dấu BOM (Excel nhận ra UTF-8)
with open(base / "bom.csv", "w", encoding="utf-8-sig", newline="") as f:
    f.write("code,name\nA,Tiếng Việt\n")
  • Đường dẫn tương đối chạy ở máy này được, máy khác thì không. FileNotFoundError thường do thư mục hiện tại khác. Tính đường dẫn từ Path(__file__) hoặc dùng đường dẫn tuyệt đối.
  • Quên encoding. Đọc file UTF-8 bằng bảng mã sai báo UnicodeDecodeError hoặc ra chữ lộn xộn. Luôn ghi rõ encoding="utf-8".
  • Quên newline="" với CSV. Có thể sinh dòng trống thừa (đặc biệt trên Windows) hoặc đọc sai ô nhiều dòng.
  • Tính toán trên giá trị CSV chưa ép kiểu. "24" + "16" ra "2416". Luôn int()/float() trước.
  • Ghi bằng "w" làm mất dữ liệu cũ. Dùng "a" nếu muốn nối thêm.

Tổng kết

  • pathlib.Path cho đường dẫn; with open(..., encoding="utf-8") cho file; "w" xóa cũ, "a" nối thêm.
  • json: dumps/loads với chuỗi, dump/load với file; ensure_ascii=False cho tiếng Việt.
  • csv.DictReader/DictWriter với newline=""; mọi ô đọc ra là chuỗi.
  • configparser đọc file kiểu odoo.conf.

Bài tiếp theo xử lý hai loại dữ liệu cực kỳ dễ sai khi nhập: ngày giờ và chuỗi cần kiểm tra bằng regex.

Câu hỏi thường gặp

Vì sao phải ghi encoding="utf-8" khi mở file? ▾
Nếu không chỉ định, Python dùng bảng mã mặc định của hệ thống nên kết quả có thể khác nhau giữa các máy. Với dữ liệu tiếng Việt, luôn ghi rõ utf-8 để tránh UnicodeDecodeError hoặc chữ lỗi.
Vì sao csv cần newline=""? ▾
Module csv tự xử lý ký tự xuống dòng bên trong ô và giữa các dòng. Mở file mà không đặt newline rỗng có thể sinh dòng trống thừa hoặc đọc sai ô nhiều dòng, nhất là trên Windows.
Khác nhau giữa json.dumps và json.dump? ▾
dumps trả về một chuỗi JSON, còn dump ghi trực tiếp vào một file đã mở. Tương tự loads đọc từ chuỗi và load đọc từ file.
Vì sao số trong file CSV đọc ra lại là chuỗi? ▾
CSV chỉ là văn bản nên csv.reader và DictReader trả mọi ô dưới dạng chuỗi. Bạn phải tự ép kiểu bằng int() hoặc float() trước khi tính toán.
