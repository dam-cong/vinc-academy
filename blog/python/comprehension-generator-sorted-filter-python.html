Comprehension, generator và sorted/filter trong Python

Xử lý danh sách gọn và nhanh là kỹ năng dùng hằng ngày khi viết code Odoo. Bài này đi qua comprehension, generator, sorted, filter, map, any, all và chỉ ra chúng tương ứng với mapped, filtered, sorted, grouped của recordset thế nào.

Cập nhật: 16/10/2026 14 phút đọc – lượt xem Đội ngũ Vinc Academy

Tóm tắt nhanh

Comprehension biến một vòng for thành một biểu thức: [c["code"] for c in courses if c["published"]]. Có bốn dạng (list, dict, set, generator), chỉ khác loại ngoặc. Generator tạo giá trị theo yêu cầu nên tiết kiệm bộ nhớ nhưng chỉ dùng được một lần. Cùng với sorted, filter, map, sum, any, all, đây là bộ công cụ xử lý danh sách mà mapped, filtered, sorted của recordset Odoo mô phỏng lại.

List comprehension: vòng for trong một dòng

Cú pháp là [biểu_thức for phần_tử in tập_hợp if điều_kiện], với phần if là tùy chọn. Dùng lại danh sách khóa học của các bài trước:

courses = [
    {"code": "ODO-F", "name": "Odoo cơ bản", "hours": 24, "published": True},
    {"code": "PY-F", "name": "Python cơ bản", "hours": 16, "published": True},
    {"code": "GIT-T", "name": "Git cho nhóm", "hours": 8, "published": False},
]

codes = [c["code"] for c in courses]
print(codes)          # ['ODO-F', 'PY-F', 'GIT-T']

long_codes = [c["code"] for c in courses if c["hours"] >= 16]
print(long_codes)     # ['ODO-F', 'PY-F']

labels = [f'{c["code"]} ({c["hours"]}h)' for c in courses]
print(labels)         # ['ODO-F (24h)', 'PY-F (16h)', 'GIT-T (8h)']

Đọc từ trái sang phải như một câu: "lấy c["code"] cho mỗi c trong courses nếu c["hours"] >= 16". Nó tương đương vòng lặp bạn đã viết ở bài 3, ngắn hơn và cho thẳng danh sách kết quả:

result = []
for c in courses:
    if c["published"]:
        result.append(c["code"])
print(result)         # ['ODO-F', 'PY-F']

# cùng kết quả, một dòng
print([c["code"] for c in courses if c["published"]])

Khi nào dùng? Khi bạn tạo một danh sách mới từ danh sách cũ bằng cách biến đổi hoặc lọc. Khi vòng lặp có nhiều bước hoặc tác dụng phụ (ghi file, gọi API), hãy giữ vòng for thường cho dễ đọc.

Dict và set comprehension

Chỉ cần đổi ngoặc: ngoặc nhọn với cặp khóa: giá trị cho dict, ngoặc nhọn với một giá trị cho set (ví dụ loại trùng):

by_code = {c["code"]: c["hours"] for c in courses}
print(by_code)        # {'ODO-F': 24, 'PY-F': 16, 'GIT-T': 8}

hour_set = {c["hours"] // 8 for c in courses}
print(sorted(hour_set))   # [1, 2, 3]

Dict comprehension rất hợp để dựng bảng tra cứu từ danh sách: ở đây by_code["PY-F"] cho số giờ ngay lập tức, thay vì duyệt cả danh sách mỗi lần.

Vòng lặp lồng nhau

pairs = [(c["code"], t) for c in courses for t in ("A", "B") if c["published"]]
print(pairs)
# [('ODO-F', 'A'), ('ODO-F', 'B'), ('PY-F', 'A'), ('PY-F', 'B')]

Các mệnh đề for liệt kê theo thứ tự lồng nhau như khi bạn viết vòng lặp thường. Nhưng nếu comprehension cần hai tầng for cộng điều kiện phức tạp, hãy tách ra vòng lặp thường: code dễ đọc quan trọng hơn code ngắn.

sorted, filter, map và các hàm tổng hợp

HàmLàm gìTrả về
sorted(ds, key=..., reverse=...)Sắp xếp theo khóalist mới
filter(hàm, ds)Giữ phần tử mà hàm trả đúngiterator (bọc list())
map(hàm, ds)Áp hàm lên từng phần tửiterator
sum, min, maxTổng, nhỏ nhất, lớn nhấtmột giá trị
any, allCó ít nhất một / mọi phần tử đúngTrue/False
 
print(sorted(courses, key=lambda c: c["hours"], reverse=True)[0]["code"])   # ODO-F
print(list(filter(lambda c: c["published"], courses))[0]["code"])           # ODO-F
print(list(map(lambda c: c["hours"] * 60, courses)))                        # [1440, 960, 480]

print(sum(c["hours"] for c in courses), max(c["hours"] for c in courses), min(c["hours"] for c in courses))
# 48 24 8
print(any(c["hours"] > 20 for c in courses), all(c["published"] for c in courses))
# True False

filter và map trả về một đối tượng iterator chứ không phải list, nên in thẳng sẽ ra <filter object ...>. Trong thực tế, nhiều người ưu tiên comprehension thay cho filter/map vì dễ đọc hơn, và chỉ giữ sorted, sum, any, all.

Biến đổi có điều kiện, enumerate và zip

Có hai chỗ đặt điều kiện trong comprehension và chúng khác nhau. if đứng sau for để loại phần tử; x if cond else y đứng trước for để biến đổi mọi phần tử theo điều kiện. Bạn cũng dùng được enumerate và zip bên trong để lấy chỉ số hoặc duyệt hai danh sách song song:

courses = [
    {"code": "ODO-F", "hours": 24, "published": True},
    {"code": "PY-F", "hours": 16, "published": True},
    {"code": "GIT-T", "hours": 8, "published": False},
    {"code": "SQL-B", "hours": 16, "published": True},
]

# if-else nằm TRƯỚC for: biến đổi theo điều kiện
print([c["code"] if c["published"] else c["code"].lower() for c in courses])
# ['ODO-F', 'PY-F', 'git-t', 'SQL-B']

# enumerate và zip trong comprehension
print([f"{i}. {c['code']}" for i, c in enumerate(courses, start=1)])
# ['1. ODO-F', '2. PY-F', '3. GIT-T', '4. SQL-B']
print({n: h for n, h in zip(["a", "b"], [1, 2])})   # {'a': 1, 'b': 2}

Sắp xếp nâng cao

Tham số key nhận một hàm trả về "khóa so sánh" cho mỗi phần tử. Muốn sắp theo nhiều tiêu chí, trả về một tuple; dấu trừ đảo chiều cho số. Mô-đun operator có itemgetter làm việc này gọn hơn lambda. Phép sắp xếp của Python là ổn định: các phần tử có khóa bằng nhau giữ nguyên thứ tự ban đầu, nên bạn có thể sắp xếp nhiều lần theo từng tiêu chí.

courses = [
    {"code": "ODO-F", "hours": 24, "published": True},
    {"code": "PY-F", "hours": 16, "published": True},
    {"code": "GIT-T", "hours": 8, "published": False},
    {"code": "SQL-B", "hours": 16, "published": True},
]

from operator import itemgetter

# nhiều khóa: giờ giảm dần, rồi mã tăng dần
print([c["code"] for c in sorted(courses, key=lambda c: (-c["hours"], c["code"]))])
# ['ODO-F', 'PY-F', 'SQL-B', 'GIT-T']

print([c["code"] for c in sorted(courses, key=itemgetter("hours", "code"))])
# ['GIT-T', 'PY-F', 'SQL-B', 'ODO-F']

# sắp xếp ổn định: hai khóa 16 giờ giữ nguyên thứ tự ban đầu
print([c["code"] for c in sorted(courses, key=lambda c: c["hours"])])
# ['GIT-T', 'PY-F', 'SQL-B', 'ODO-F']

print(max(courses, key=lambda c: c["hours"])["code"])   # ODO-F

Gom nhóm và đếm

Bài 4 bạn đã gom nhóm bằng setdefault. Thư viện chuẩn có công cụ chuyên dụng hơn: defaultdict(list) tự tạo list rỗng cho khóa mới, Counter đếm số lần xuất hiện, và itertools.groupby gom các phần tử liền kề. Hãy cẩn thận với cái cuối: groupby chỉ gom những phần tử đứng cạnh nhau, nên dữ liệu phải được sắp xếp theo cùng khóa trước.

courses = [
    {"code": "ODO-F", "hours": 24, "published": True},
    {"code": "PY-F", "hours": 16, "published": True},
    {"code": "GIT-T", "hours": 8, "published": False},
    {"code": "SQL-B", "hours": 16, "published": True},
]

from collections import defaultdict, Counter
from itertools import groupby
from operator import itemgetter

groups = defaultdict(list)
for c in courses:
    groups[c["hours"]].append(c["code"])
print(dict(groups))   # {24: ['ODO-F'], 16: ['PY-F', 'SQL-B'], 8: ['GIT-T']}

print(Counter(c["hours"] for c in courses))   # Counter({16: 2, 24: 1, 8: 1})

# groupby chỉ gom các phần tử LIỀN KỀ: phải sắp xếp trước
srt = sorted(courses, key=itemgetter("hours"))
print({h: [c["code"] for c in g] for h, g in groupby(srt, key=itemgetter("hours"))})
# {8: ['GIT-T'], 16: ['PY-F', 'SQL-B'], 24: ['ODO-F']}
print({h: [c["code"] for c in g] for h, g in groupby(courses, key=itemgetter("hours"))})
# {24: ['ODO-F'], 16: ['SQL-B'], 8: ['GIT-T']}   <- sai: mất 'PY-F'!

Trong Odoo, records.grouped(key) làm việc gom nhóm này và trả dict từ khóa sang recordset, nên bạn hiếm khi phải tự viết groupby.

Generator: tạo giá trị theo yêu cầu

Đổi ngoặc vuông của list comprehension thành ngoặc tròn là bạn có generator expression: nó không dựng cả danh sách trong bộ nhớ mà sinh từng giá trị khi được hỏi. Hàm dùng yield thay cho return cũng tạo ra generator: mỗi lần được gọi tiếp, nó chạy tiếp từ chỗ dừng lần trước, nhớ cả giá trị biến và câu lệnh đang thực thi.

gen = (c["hours"] for c in courses)    # generator expression: ngoặc tròn
print(type(gen))                        # <class 'generator'>
print(next(gen), next(gen), list(gen))  # 24 16 [8]

def hours_gen(items):
    for c in items:
        yield c["hours"]                # yield: trả từng giá trị, nhớ vị trí

g = hours_gen(courses)
print(next(g), sum(g))                  # 24 24

Lợi ích lớn là bộ nhớ. Với một triệu bản ghi, list chứa hết, còn generator chỉ giữ một phần tử một lúc. Truyền thẳng generator vào sum, max, any như sum(c["hours"] for c in courses) là thói quen tốt, và bạn đã thấy kiểu viết này trong ví dụ any(course.is_published for course in self) ở series Odoo.

import sys
big_list = [i for i in range(100000)]
big_gen = (i for i in range(100000))
print(sys.getsizeof(big_list) > sys.getsizeof(big_gen))    # True
print(sum(i for i in range(10)))                          # 45

Mẫu "tìm phần tử đầu tiên khớp"

first = next((c for c in courses if c["hours"] < 10), None)
print(first["code"])                                          # GIT-T
print(next((c for c in courses if c["hours"] > 100), None))   # None

next(generator, mặc_định) trả phần tử đầu tiên rồi dừng, không duyệt hết danh sách; nếu không có phần tử nào thì trả mặc định thay vì báo lỗi.

Tương ứng trong Odoo: mapped, filtered, sorted

Recordset của Odoo có sẵn các phương thức làm đúng những việc trên, nhận cả hàm lẫn tên field. Tài liệu ORM mô tả:

Phương thức recordsetTương đương Python thuầnGhi chú từ tài liệu
records.mapped('name')[r.name for r in records]Nhận hàm hoặc chuỗi field có dấu chấm ('partner_id.bank_ids'); trả list, hoặc recordset nếu kết quả là recordset (thứ tự không đảm bảo)
records.filtered(f)[r for r in records if f(r)]Nhận hàm, domain hoặc chuỗi field như "partner_id.vat"; trả recordset
records.sorted(key)sorted(records, key=key)key là hàm hoặc chuỗi như 'name DESC, id'; không có thì theo thứ tự mặc định của model
records.grouped(key)dict gom nhómTrả dict từ kết quả của key sang recordset
 
# danh sách tên (Python thuần ~ recordset)
names = [c.name for c in courses]            # tương đương courses.mapped('name')

# lọc
published = [c for c in courses if c.is_published]   # tương đương courses.filtered('is_published')

# sắp xếp
ordered = sorted(courses, key=lambda c: c.start_date)   # tương đương courses.sorted('start_date')

# tính tổng giờ
total = sum(c.duration_hours for c in courses)          # tương đương sum(courses.mapped('duration_hours'))

Điểm khác quan trọng: các phương thức recordset trả về recordset (vẫn gọi tiếp được .write(), .mapped()), còn comprehension trả list thường.

Thực hành: gom khóa học theo trạng thái

groups = {}
for c in courses:
    groups.setdefault(c["published"], []).append(c["code"])
print(groups)          # {True: ['ODO-F', 'PY-F'], False: ['GIT-T']}

# viết lại bằng comprehension + sorted
published_codes = sorted(c["code"] for c in courses if c["published"])
unpublished_codes = sorted(c["code"] for c in courses if not c["published"])
print(published_codes, unpublished_codes)   # ['ODO-F', 'PY-F'] ['GIT-T']

Hãy thử viết thêm một comprehension tạo dict {code: name} chỉ gồm các khóa đã xuất bản, rồi dùng next(...) để tìm khóa đầu tiên dài hơn 20 giờ.

Lỗi hay gặp khi mới học

  • Dùng lại generator đã cạn. Sau khi duyệt hết, generator trống; lần duyệt thứ hai cho []. Cần dùng nhiều lần thì dựng list.
  • Quên bọc list() quanh filter/map. In ra <filter object at ...> thay vì kết quả.
  • Comprehension quá phức tạp. Hai tầng for cộng nhiều điều kiện khiến người đọc phải giải mã. Hãy tách ra vòng lặp thường hoặc hàm có tên.
  • Nhầm ngoặc. [...] là list, {...} là set hoặc dict, (...) là generator, không phải tuple comprehension.

Tổng kết

  • Comprehension tạo list/dict/set mới từ dữ liệu cũ bằng một biểu thức; chỉ dùng khi còn dễ đọc.
  • Generator (( ... ) hoặc yield) sinh giá trị theo yêu cầu, tiết kiệm bộ nhớ, chỉ dùng một lần.
  • sorted, sum, min, max, any, all, next(..., mặc_định) là bộ công cụ hằng ngày.
  • mapped, filtered, sorted, grouped của recordset Odoo làm cùng việc nhưng trả recordset.

Câu hỏi thường gặp

List comprehension khác vòng for ở điểm nào? ▾
Comprehension là biểu thức tạo ngay một danh sách mới từ danh sách cũ, ngắn hơn vòng for kèm append. Nên dùng khi chỉ biến đổi hoặc lọc; nếu vòng lặp có nhiều bước hoặc tác dụng phụ thì giữ vòng for thường.
Generator khác list ở điểm nào? ▾
Generator không dựng cả danh sách trong bộ nhớ mà sinh từng giá trị khi được hỏi, nên tiết kiệm bộ nhớ với dữ liệu lớn, nhưng chỉ duyệt được một lần.
mapped và filtered của Odoo giống gì với Python thuần? ▾
mapped giống comprehension biến đổi từng bản ghi, filtered giống comprehension có điều kiện if. Khác biệt là các phương thức recordset nhận cả tên field và trả về recordset, còn comprehension trả về list.
Làm sao lấy phần tử đầu tiên thỏa điều kiện? ▾
Dùng next với generator và giá trị mặc định, ví dụ next((c for c in courses if c["hours"] < 10), None). Nó dừng ngay khi tìm thấy và trả None nếu không có phần tử nào.
