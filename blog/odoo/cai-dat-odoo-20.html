Cài đặt Odoo 20 từ source và Docker cho developer

Một môi trường phát triển chuẩn giúp bạn tiết kiệm hàng giờ debug về sau. Bài này hướng dẫn hai cách cài Odoo 20 mà Vinc Academy dùng khi đào tạo, kèm các lỗi học viên hay gặp và cách xử lý.

Cập nhật: 16/10/2026 12 phút đọc – lượt xem Đội ngũ Vinc Academy

Tóm tắt nhanh

Để cài Odoo 20 cho phát triển, bạn cần Python 3.12+, PostgreSQL 16+ và Git. Clone nhánh 20.0 từ GitHub, tạo user PostgreSQL riêng, cài thư viện phụ thuộc rồi chạy odoo-bin; hoặc dùng Docker Compose với image odoo:20.0 và postgres:16. Truy cập http://localhost:8069, đăng nhập admin/admin và bật developer mode.

Chuẩn bị trước khi cài

Odoo 20 nâng yêu cầu tối thiểu so với các bản trước, nên máy đang chạy Odoo 17 hay 18 chưa chắc đã đủ. Kiểm tra danh sách sau:

Khuyến nghị của Vinc Academy: người học lập trình Odoo nên làm quen với cách cài từ source trước, vì đó là cách hiểu rõ nhất Odoo khởi động thế nào. Docker là kỹ năng bổ sung rất đáng học khi bạn bắt đầu làm dự án.

Cách 1: Cài Odoo 20 từ source trên Ubuntu

Các bước dưới đây dùng Ubuntu/Debian, môi trường phổ biến nhất của developer Odoo. Ghi chú cho Windows và macOS nằm ở cuối mục.

Bước 1: Lấy mã nguồn

Chỉ lấy đúng nhánh 20.0 để tiết kiệm dung lượng. Tham số --depth 1 bỏ qua lịch sử commit, giúp clone nhanh hơn nhiều:

mkdir -p ~/odoo-dev && cd ~/odoo-dev
git clone https://github.com/odoo/odoo.git --branch 20.0 --single-branch --depth 1

Nếu bạn có quyền truy cập Odoo Enterprise, clone thêm repo odoo/enterprise vào cùng thư mục ~/odoo-dev. Repo này chỉ chứa module bổ sung, vẫn phải chạy trên nền Community.

Bước 2: Cài PostgreSQL và tạo user riêng

Odoo không cho kết nối bằng user quản trị postgres. Hãy tạo một user trùng tên tài khoản Linux của bạn, có quyền tạo database:

sudo apt install postgresql
sudo -u postgres createuser -d -R -S $USER
createdb $USER

Kiểm tra phiên bản bằng psql --version. Nếu kho gói của bản Ubuntu bạn dùng cung cấp phiên bản cũ hơn 16, hãy cài từ kho chính thức của PostgreSQL.

Bước 3: Cài thư viện phụ thuộc

Tài liệu Odoo khuyến nghị dùng script đi kèm mã nguồn, script này cài các gói hệ thống tương ứng của Debian/Ubuntu:

cd ~/odoo-dev/odoo
sudo ./setup/debinstall.sh

Nếu muốn tách riêng thư viện cho từng dự án, bạn có thể dùng môi trường ảo Python và cài qua requirements.txt. Cách này cần các gói hệ thống để biên dịch (như libpq-dev, libldap2-dev, libsasl2-dev):

python3 -m venv ~/odoo-dev/venv
source ~/odoo-dev/venv/bin/activate
pip install -r requirements.txt

Bước 4: Chạy Odoo

python3 odoo-bin --addons-path=addons -d odoo20_dev

Khi log hiện dòng odoo.modules.loading: Modules loaded., mở trình duyệt tại http://localhost:8069 và đăng nhập bằng admin / admin. Database odoo20_dev được tạo tự động ở lần chạy đầu tiên.

Lưu ý về dữ liệu demo

Từ Odoo 20, database mới mặc định không có dữ liệu demo. Khi học, nên thêm --with-demo lúc tạo database để có sẵn khách hàng, sản phẩm, đơn hàng mẫu mà thực hành.

Ghi chú cho Windows và macOS

  • Windows: cài Build Tools for Visual Studio (gói C++), thêm thư mục bin của PostgreSQL vào PATH, tạo user đăng nhập có quyền tạo database bằng pgAdmin. Cài thư viện bằng pip install setuptools wheel rồi pip install -r requirements.txt, và chạy kèm thông tin kết nối: python odoo-bin -r dbuser -w dbpassword --addons-path=addons -d odoo20_dev.
  • macOS: cài Command Line Tools bằng xcode-select --install, cài thư viện hệ thống qua Homebrew hoặc MacPorts, PostgreSQL qua Homebrew hoặc Postgres.app, sau đó tạo user và chạy giống Linux.

Cách 2: Chạy Odoo 20 bằng Docker Compose

Image chính thức odoo trên Docker Hub đã có tag 20.0. Thay vì gõ nhiều lệnh docker run, Vinc Academy dùng một file Compose để cả lớp có môi trường giống hệt nhau:

odoo20/docker-compose.yml

services:
  db:
    image: postgres:16
    environment:
      POSTGRES_USER: odoo
      POSTGRES_PASSWORD: odoo
      POSTGRES_DB: postgres
    volumes:
      - db-data:/var/lib/postgresql/data

  odoo:
    image: odoo:20.0
    depends_on:
      - db
    ports:
      - "8069:8069"
    environment:
      HOST: db
      USER: odoo
      PASSWORD: odoo
    volumes:
      - odoo-data:/var/lib/odoo          # filestore, session
      - ./addons:/mnt/extra-addons       # module tự viết

volumes:
  db-data:
  odoo-data:
cd odoo20
mkdir -p addons
docker compose up -d
docker compose logs -f odoo

Mở http://localhost:8069, Odoo sẽ hiện trang tạo database. Module bạn đặt trong thư mục ./addons sẽ xuất hiện trong container tại /mnt/extra-addons.

Điểm dễ sai: phiên bản PostgreSQL

Nhiều hướng dẫn và ví dụ Docker cũ vẫn dùng postgres:15. Odoo 20 yêu cầu PostgreSQL 16 trở lên, vì vậy hãy dùng postgres:16 (hoặc mới hơn) ngay từ đầu, tránh phải chuyển dữ liệu về sau.

Bật developer mode

Developer mode mở ra các công cụ kỹ thuật: xem cấu trúc view, tên field, model, chỉnh menu, action… Đây là thứ developer Odoo bật đầu tiên mỗi ngày. Có nhiều cách tương đương:

  • Từ Settings: vào ứng dụng Settings, kéo xuống mục Developer Tools và chọn Activate the developer mode.
  • Qua URL: thêm ?debug=1 vào địa chỉ, ví dụ http://localhost:8069/odoo?debug=1; dùng ?debug=0 để tắt.
  • Debug JavaScript: dùng ?debug=assets để tải file JS/CSS chưa nén, dễ đọc khi debug giao diện.
  • Command palette: nhấn Ctrl + K (macOS: Cmd + K) rồi gõ "debug".

Khi bật thành công, biểu tượng con bọ xuất hiện trên thanh menu. Một số công cụ trong đó có thể thay đổi dữ liệu hệ thống, chỉ dùng trên database phát triển.

Các tham số odoo-bin cần nhớ

Tham sốTác dụng
--addons-pathDanh sách thư mục chứa module, cách nhau bởi dấu phẩy
-dTên database làm việc
-iCài module trước khi chạy server (cần đi kèm -d)
-uCập nhật module sau khi sửa code (cần đi kèm -d)
--devTính năng hỗ trợ phát triển, ví dụ xml đọc view trực tiếp từ file, reload tự khởi động lại khi sửa Python; all bật nhiều tính năng cùng lúc. Không dùng trên production
--with-demoCài dữ liệu demo cho database mới
-p / --http-portĐổi cổng HTTP (mặc định 8069)
-c / -sDùng file cấu hình / lưu các tham số hiện tại vào file cấu hình

Mẹo: chạy một lần với đầy đủ tham số kèm -c ~/odoo-dev/odoo20.conf -s, từ lần sau chỉ cần python3 odoo-bin -c ~/odoo-dev/odoo20.conf.

Tạo khung module đầu tiên

Môi trường đã sẵn sàng, hãy tạo thư mục riêng cho module tự viết, tách khỏi mã nguồn Odoo. Lệnh scaffold sinh sẵn khung thư mục chuẩn:

cd ~/odoo-dev
mkdir -p custom-addons
python3 odoo/odoo-bin scaffold vinc_course custom-addons

cd odoo
python3 odoo-bin --addons-path=addons,../custom-addons \
    -d odoo20_dev -i vinc_course --dev=xml

Vào Apps (nhớ bật developer mode), tìm vinc_course để thấy module vừa cài. Cấu trúc bên trong module sẽ được giải thích chi tiết ở bài tiếp theo.

Công cụ nên cài thêm

  • Trình soạn thảo: VS Code hoặc PyCharm. Bật kiểm tra PEP8 cho Python và ESLint cho JavaScript.
  • Quản lý PostgreSQL: pgAdmin hoặc DBeaver để xem bảng mà ORM tạo ra, rất hữu ích khi học model.
  • Debug Python: debugger của editor, hoặc pip install ipdb rồi đặt import ipdb; ipdb.set_trace() tại dòng cần dừng.
  • Odoo shell: python3 odoo-bin shell -c ~/odoo-dev/odoo20.conf mở console Python có sẵn biến env để thử ORM. Thay đổi chỉ được lưu khi bạn gọi env.cr.commit().

Hai lỗi người mới hay vấp

  • Chạy -i hoặc -u mà quên -d. Theo tài liệu CLI, hai tham số này cần đi kèm tên database. Hãy tập thói quen luôn viết đủ: -d odoo20_dev -u tên_module.
  • Sửa dữ liệu trong odoo shell rồi thoát, mở lại thấy chưa đổi. Shell chỉ lưu thay đổi khi bạn gọi env.cr.commit(). Đây là chủ ý để bạn thử thoải mái mà không làm hỏng database.

Câu hỏi thường gặp

Nên cài Odoo 20 bằng source hay Docker? ▾
Nếu bạn học để trở thành Odoo Developer, nên cài từ source vì dễ đọc mã nguồn, đặt breakpoint và debug. Docker phù hợp khi cần dựng nhanh một môi trường sạch, chạy nhiều phiên bản song song hoặc chuẩn bị triển khai.
Tài khoản đăng nhập mặc định của Odoo là gì? ▾
Với database tạo bằng tham số -d khi chạy odoo-bin, tài khoản quản trị mặc định là admin, mật khẩu admin. Hãy đổi mật khẩu nếu môi trường có thể truy cập từ bên ngoài.
Vì sao database mới không có dữ liệu demo? ▾
Ở Odoo 20, mặc định database mới không cài dữ liệu demo. Thêm tham số --with-demo khi tạo database nếu bạn muốn có dữ liệu mẫu để học và thử nghiệm.
Odoo 20 có chạy với PostgreSQL 15 không? ▾
Không nên. Tài liệu cài đặt chính thức của Odoo 20 yêu cầu PostgreSQL 16 trở lên. Nhiều ví dụ Docker cũ vẫn dùng postgres:15, bạn cần đổi sang postgres:16 hoặc mới hơn.
